# 🏛️ Corona Properties Limited — Ultra Premium Website

## 🎯 Project Overview
A premium, multi-page Next.js website for Corona Properties Limited (a residential land-selling company based in Dhaka, Bangladesh). Deep navy + royal gold palette, smooth animations, full-screen hero sections, and elegant typography — matching or exceeding goldsandsgroup.com.

## 🎨 Design System (Royal Gold & Navy)
- Primary Navy: `#0a1a3e`, Navy Light: `#1a2a5e`
- Royal Gold: `#c9a96e`, Champagne Gold: `#e8d4a8`
- Off-white: `#faf8f4`, Charcoal: `#1a1a1a`
- Fonts: **Playfair Display** + **Cormorant Garamond** (headings), **Inter** / **Poppins** (body)

## 🛠️ Tech Stack
Next.js 14 (App Router) · TypeScript · Tailwind CSS · Framer Motion · Lucide React · Next.js Image

## 📄 Pages (8 Premium Pages)
1. **Home** (`/`) — Hero, Stats, About teaser, Featured Properties, Why Choose Us, Process, Testimonials, CTA, Newsletter
2. **About Us** (`/about`) — Story, Vision/Mission, Values, Timeline, Team
3. **Properties** (`/properties`) — Filter bar + grid + cards
4. **Property Detail** (`/properties/[slug]`) — Gallery, info, amenities, map, contact form
5. **Services** (`/services`) — Service cards + process
6. **Gallery** (`/gallery`) — Filterable lightbox gallery
7. **Blog** (`/blog` + `/blog/[slug]`) — Listing + detail pages
8. **Contact** (`/contact`) — Form + map + FAQ

## 🧩 Component Architecture
```
app/ → 8 page routes + layout.tsx + globals.css + sitemap.ts + robots.ts
components/
  ├── layout/ → TopBar.tsx, Navbar.tsx, Footer.tsx, Preloader.tsx
  ├── ui/ → Button.tsx, SectionHeading.tsx, PageHero.tsx, ScrollToTop.tsx, ScrollProgress.tsx
  ├── home/ → Hero.tsx, Stats.tsx, AboutTeaser.tsx, FeaturedProperties.tsx, WhyChooseUs.tsx, Process.tsx, Testimonials.tsx, CTABanner.tsx, Newsletter.tsx
  └── property/ → PropertyCard.tsx, PropertyFilter.tsx
lib/ → data.ts (properties, blog, team), constants.ts (logo, contact)
public/images/
```

## 🚀 Implementation Steps
1. Create config files (package.json, next.config.js, tsconfig.json, tailwind.config.ts, postcss.config.js)
2. Configure design system (Tailwind theme, fonts, globals.css)
3. Build layout components (TopBar, Navbar, Footer, Preloader)
4. Build UI kit (Button, SectionHeading, PageHero, ScrollToTop)
5. Build data layer (data.ts with properties/blog/team, constants.ts)
6. Build Home page with all 9 sections
7. Build About Us page
8. Build Properties listing + Property Detail pages
9. Build Services page
10. Build Gallery page with lightbox
11. Build Blog listing + detail pages
12. Build Contact page with form + map + FAQ
13. Add SEO (metadata, sitemap, robots) + final polish
14. Install dependencies and verify build (`npm install && npm run build`)
